## Realtime listener

Use `listener.start()` and `listener.stop()` for connection lifecycle. `listener.requestOldMessages()` and `listener.requestOldReactions()` accept a thread type and cursor. `listener.sendWs()` accepts a protocol frame description. Subscribe with the standard EventEmitter methods. The pinned listener declares 16 events. [Pinned listener declaration](https://cdn.jsdelivr.net/npm/zca-js@2.2.0/dist/apis/listen.d.ts) · [Pinned listener implementation](https://github.com/RFS-ADRENO/zca-js/blob/dadfef18bcac53537741855c99f084152da1fad9/src/apis/listen.ts)

| Area | Events |
| --- | --- |
| Connection lifecycle | `connected`, `disconnected`, `closed`, `error` |
| Messages and history | `message`, `old_messages`, `undo` |
| Receipts and typing | `delivered_messages`, `seen_messages`, `typing` |
| Reactions | `reaction`, `old_reactions` |
| Friend and group changes | `friend_event`, `group_event` |
| Attachment completion | `upload_attachment` |
| WebSocket session key | `cipher_key` |

Treat `getCookie()` output, `getContext()` output, and `cipher_key` payloads as credentials. `custom()` supplies an extension callback with the full session context and is for trusted code running in the same process.
